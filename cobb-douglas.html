The Cobb-Douglas production function is one of the most enduring models in economics — first estimated by Charles Cobb and Paul Douglas in 1928 using U.S. manufacturing data. This project applies that same original dataset to replicate and interpret the estimation using OLS regression in R, recovering the labour and capital elasticities and drawing practical implications for firm strategy.

The model is log-linearized to allow estimation via ordinary least squares. Taking the natural log of both sides of Q = A · Lβ · Kγ converts a nonlinear relationship into a tractable linear regression, with the slope coefficients directly interpretable as output elasticities.

"A 1% increase in labour raises output by roughly 0.81%. A 1% increase in capital raises it by only about 0.23%. Labour is more than three times as productive at the margin."

Author's OLS estimate
Estimated Model

ln(Q) = ln(A) + β · ln(L) + γ · ln(K)

ln(Q) = −4.180 + 0.811 · ln(L) + 0.231 · ln(K)

Interpretation

1. Labour vs. Capital Intensity

Since the coefficient on labour (0.811) is greater than the coefficient on capital (0.231), the firm should be labour intensive. A 1% increase in labour raises output by approximately 0.81%, while a 1% increase in capital only raises output by approximately 0.23%. Labour is more than three times as productive at the margin — capital was a supporting input, not the primary driver of output growth in this era of U.S. manufacturing.

2. Returns to Scale

β + γ = 0.811 + 0.231 = 1.041. The firm exhibits increasing returns to scale — slightly above 1, meaning a 1% increase in both inputs raises output by about 1.04%. This differs from a firm with decreasing returns, which would face diminishing gains from expansion and a natural optimal size. Here the incentive structure favours growth.

3. Optimal Size Advice

Since the firm has increasing returns to scale, it benefits from growing larger — each unit of expansion yields slightly more than proportional output gains. In the short run, since capital is typically fixed, the firm should focus on adding labour to capture those gains. In the long run, the firm should scale both labour and capital together, prioritizing labour given its much stronger effect on output, to sustain and potentially amplify the increasing returns.

4. Model Fit

The R² of 0.9572 means labour and capital explain about 95.7% of the variation in output — a very strong fit. Both coefficients are highly significant (Labour ***, Capital **), and the overall F-statistic p-value of 4.255e-15 confirms the model is solid.

R Pipeline

Full analysis pipeline in R, from raw data import through log transformation, OLS estimation, and 3D visualization.

# 01_setup_and_data.R

install.packages("plotly")
library(plotly)

cobb_douglas_data <- read.csv("~/Downloads/Cobb Douglas Data.csv")
View(cobb_douglas_data)
colnames(cobb_douglas_data)
# 02_log_transform_ols.R

cobb_douglas_data$lnL <- log(cobb_douglas_data$Labor)
cobb_douglas_data$lnK <- log(cobb_douglas_data$Kapital)
cobb_douglas_data$lnQ <- log(cobb_douglas_data$Q)

cobb_model <- lm(lnQ ~ lnL + lnK, data = cobb_douglas_data)
summary(cobb_model)
# 03_3d_visualization.R

plot_ly(cobb_douglas_data, x = ~lnK, y = ~lnL, z = ~lnQ,
        type = "scatter3d", mode = "markers",
        marker = list(color = ~lnQ, colorscale = "Viridis", showscale = TRUE)) %>%
  layout(title = "Production Data Input-Output",
         scene = list(xaxis = list(title = "ln(Capital)"),
                      yaxis = list(title = "ln(Labor)"),
                      zaxis = list(title = "ln(Output)")))

Methodology

Model Specification

  • Cobb-Douglas: Q = A · Lβ · Kγ
  • Log-linearized: ln(Q) = ln(A) + β·ln(L) + γ·ln(K)
  • Estimated via OLS using R's lm()
  • Intercept = ln(A) = −4.180; implied A ≈ 0.015

Data

  • Original Cobb-Douglas (1928) dataset
  • U.S. manufacturing sector, 1899–1922
  • 24 annual observations
  • Variables: Labour (L), Capital (K), Output (Q)

Returns to Scale Test

  • β + γ = 0.811 + 0.231 = 1.041
  • > 1 → Increasing returns to scale
  • < 1 → Decreasing returns to scale
  • = 1 → Constant returns to scale

Limitations

  • Small sample (n = 24) limits precision
  • Index measures — not physical units
  • Potential multicollinearity between L and K
  • Historical data; context differs from modern firms

Data Citation

Cobb, C. W., & Douglas, P. H. (1928). A theory of production. The American Economic Review, 18(1), 139–165. Original dataset reproduced in Paul H. Douglas, The Theory of Wages (Macmillan, 1934). Data accessed via course materials, Adams State University.
